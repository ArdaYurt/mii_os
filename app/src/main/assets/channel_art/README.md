# Channel art pack

Drop a 16:9 image named after an app's package here to give that app 4K channel art,
for example `com.netflix.ninja.webp` or `com.plexapp.android.webp`.

- Use 3840×2160 lossless WebP. The launcher decodes it down to tile size, so large
  files cost disk space but not memory.
- Art from this folder wins over the app's own banner and icon.
